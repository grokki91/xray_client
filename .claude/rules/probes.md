# Пробы, улики, адаптеры, мост

## Прежде чем добавить пробу

- Различает ли гипотезы улика, которая уже есть? Правило бесплатно; проба к серверу — бюджет и
  след в сети.
- Проба идёт, только когда её исход меняет вывод: P2 — если эталон не прошёл, P3m — если клиент
  сам не шлёт X25519MLKEM768, P6 при открытом порте — только с известным портом SSH. Порядок —
  от дешёвой к дорогой: TCP не установился — TLS и эталон не запускаются.

## Бюджет и сокеты

- К серверу — только через `r.slot` и бюджет этого сервера (`Engine.Budget(ServerKey)`);
  лимиты — AGENTS.md, «Сеть». Нет слота — не молча: `outcome: budget` в улике или `skip` с
  причиной в шаге; пауза до 65 с — сама, дольше — с согласия.
- Сокеты проб сети и сервера — через `r.dial`: при TUN клиента они привязаны к физическому
  адаптеру, иначе проба меряет тоннель клиента, а не сеть. Эталонное ядро — через диалер
  приложения, у xmux `maxConcurrency`: одна проба — одно TLS.
- TLS к серверу и к маске — отпечатком клиента (`r.clientFP`); эталон другим отпечатком
  (`refFP`, P3m) — только после ответа на отпечаток клиента: смена отпечатка во время заморозки
  её продлевает.
- Наружу ничего не слушает; права администратора — только по согласию и после базового
  вердикта (pktmon).

## Улика

- ID — из каталога проверок (`docs/architecture.md` §6; добавленные позже — в
  `docs/implementation.md`). Факты плоские; исход — строковое перечисление (`outcome`), и новое
  значение появляется вместе с гипотезой, которая его читает.
- `Summary` — человеческим языком, через редактор (`r.red`); не выполнена — `Skipped` с
  причиной; недостающее, которое меняет вывод, — `r.missing(код)` с текстом в
  `taxonomy.yaml: missing`.
- Адрес, порт ≠ 443, SNI, алиас и порт SSH, MAC, имя профиля — не в факты, а в `Secret`
  (только DPAPI-файл сеанса).

## Windows и клиенты

- Факты Windows — один скрипт PowerShell 5.1, только чтение, через `-EncodedCommand` (stdin он
  читает построчно); новый факт — поле в том же скрипте и фикстура вывода.
- Файлы клиентов только читаются, SQLite — через копию; неизвестная версия — `support:
  partial`, остальные проверки идут.
- Пути, форматы логов и слова интерфейса клиента — по его исходнику или релизу, с источником;
  не проверено на машине — так и пометить в `docs/implementation.md`.

## Мост и сервер

- Вывод `xm doctor` / `xm health` — по `ui/doctor.py` / `ui/health.py` сервера; изменение
  контракта — `schema.major` и тест в `internal/bridge`. На сервер — только соль и длина окна,
  команды — только из allowlist.
- Разбор ClientHello (`internal/hello`) — порт `parse_hello` из `ui/doctor.py`: менять вместе;
  фикстура — `testdata/hello/`, копия `tests/fixtures/doctor-hellos.json` сервера.

## Проверка

- Проба — тест на симуляторе `internal/sim` (настоящий REALITY Xray-core на петле, маска, цель,
  SOCKS-«клиент») с подсчётом TLS и TCP к серверу.
- Фикстуры — обезличенные (AGENTS.md).
