# README и docs

- `README.md` — для пользователя: что проверяется, как пользоваться, настройки,
  конфиденциальность. Без истории разборов и внутренних ID проверок.
- `docs/implementation.md` — состояние: что сделано, чем реализация отличается от проекта и
  почему, что не сделано. Новая запись — до 5 строк: что и почему; хроника случая — в тело
  коммита.
- `docs/architecture.md` — проект v0.1: без просьбы владельца не правится; устаревшее в нём —
  строкой в `implementation.md`, «Отличия от проекта».
